# What this is

Code for the CHI 2026 paper *"Scaffolded Vulnerability: Chatbot-Mediated
Reciprocal Self-Disclosure and Need-Supportive Interaction in Couples."*
**Echo** is a Telegram bot (`main.py`) that long-polls the Telegram Bot API
via `python-telegram-bot` and calls the OpenAI chat-completions API directly
over `httpx` to run structured, phased self-disclosure conversations between
two partners in a Telegram group chat. It is a batch/polling process, not a
web app or HTTP service — there is no server to start, no port to check, and
no offline dataset or notebook to run. The paper's experiment is a live
72-person user study conducted through this bot; this repository does not
contain the study's collected data or analysis scripts, only the bot itself.

`.engelbart/setup.sh` created a venv at `.engelbart/venv` and installed
`requirements.txt` into it as-is (no repo files were modified; no pins were
broken or needed).

## What you can actually run here

There is no analysis, benchmark, or notebook to reproduce — the only
"experiment" this repo can run is the live bot conversation itself, and that
requires live credentials it cannot supply on its own.

1. **Verify the install (already done, ~1s):**
   ```bash
   bash .engelbart/check.sh
   ```
   Imports `main.py`, `prompts.py`, and all dependencies in the venv. Does
   not start the bot (the polling loop is behind `if __name__ == '__main__'`
   in `main.py`, so importing the module is safe and requires no
   credentials).

2. **Run the actual bot (needs credentials you must supply — not possible in
   this sandbox):**
   ```bash
   .engelbart/venv/bin/python main.py
   ```
   Requires a `.env` file in the repo root with:
   - `TELEGRAM_TOKEN` — a bot token from `@BotFather` on Telegram
   - `OPENAI_API_KEY` — an OpenAI API key (billed account; the bot calls
     `gpt-4o`-class chat completions per message)
   - `API_MODEL` (e.g. `gpt-4o`) and `TELEGRAM_BOT_NAME` (e.g.
     `@your_bot_username`)

   Once running, it long-polls Telegram (no local port, nothing to
   health-check). Usage is entirely inside a two-person Telegram group chat:
   add the bot, run `/start`, then `/continue` to advance phases and
   `/pause` to pause. Each turn costs one OpenAI API call; a full phased
   session (per `prompts.py`) is a multi-day, multi-message human
   conversation, not a scripted run with a fixed duration.

There is no GPU requirement (all inference is a remote OpenAI API call) and
no dataset to download — the only missing inputs are the Telegram bot token
and OpenAI API key above, which only a human with those accounts can provide.
